# 危險區

設定頁最下面、紅框的卡片（`.card.danger-zone`）。原則：**說清楚會刪什麼、在哪裡、能不能救回**，要打字才能執行。
程式：`ui.js` 的 `confirmTyped`，範例在 `app.js` 的 `clearLocal`、`wipeAll`。

## 兩級

| | 清除這台電腦的資料 | 刪除所有資料 |
| --- | --- | --- |
| 刪什麼 | 這台瀏覽器的 localStorage | 這台＋Google 試算表裡的資料列（試算表檔案保留） |
| 有登入時 | 試算表不受影響，之後重新下載。**還沒同步的 N 筆修改會不見**（要寫出數字） | 本網站無法復原；可以從試算表「檔案 → 版本記錄」還原 |
| 沒登入時 | 資料沒有備份，清掉就沒了，建議先匯出 | 同左 |
| 打字確認 | 「清除」 | 「刪除」 |
| 按鈕樣式 | `btn-outline` | `btn-danger`（沒資料時 disabled） |

## 規則

- 每一列：左邊**粗體名稱＋一行說明**（說明依「有沒有登入」換內容），右邊一個按鈕（`.settings-row`）。
- 確認視窗（`confirmTyped`）：
  - 標題是問句，跟按鈕同一個動詞（「刪除所有資料？」→「確定刪除」）。
  - 內文寫**數量**（「會刪除 128 筆資料」）和**範圍**（這台／試算表）。
  - `restore` 寫怎麼救回，或明講救不回並建議先匯出。
  - 打對字才能按；最後一步是實心紅 `btn-danger-solid`。
- 刪除試算表的資料時要等同步完成；同步失敗要**丟錯誤**讓視窗顯示「這台已刪除，但試算表還沒同步成功…請按立即同步」，不能默默成功。
- 只刪資料、**保留設定**（`settings` 表），使用者不用重設。
- 登出也算危險動作：登出會清掉這台的資料，還有沒同步的修改要寫出數字。

## 進階（需要時再做）

- **範圍刪除**（finance-watcher）：例如「刪除某年以前的資料」。先 dry-run 算出會刪幾筆給使用者看，
  確認時再算一次，數字不一樣（中間同步進新資料）就停下來重問。
- **鎖住的資料**（color-picker 帳務）：已結帳的資料不在一般刪除的範圍，要先取消結帳。
